# Raspberry Pi Freezer Monitor

University project for monitoring freezer temperature with Raspberry Pi.

## Hardware

- Raspberry Pi 4 Model B
- SHT31 temperature sensor
- LCD 16x2 I2C display
- Green LED
- Yellow LED
- Red LED
- UP button
- DOWN button

## Description

The system monitors the temperature inside a freezer.

The default critical temperature limit is -3 degrees Celsius.

The LEDs indicate the freezer condition:

- Green - normal temperature
- Yellow - warning temperature
- Red - critical temperature

The UP and DOWN buttons are used to change the temperature limit.
